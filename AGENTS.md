# uCode

- Работать только внутри этой папки. Без отдельного запроса зависимости автоматически не устанавливать; запрос пользователя от 27.10.2026 явно разрешает расширенную локальную установку для этого сравнения в `.venv/`, `tools/`, `node_modules/`.
- Вести README и docs/WORK_LOG.md: архитектура, команды, проверенные результаты, ограничения и следующий шаг.
- Параметры обоих масштабов: обычный QR Code, M, модуль 0,5 мм, поле 4 модуля, векторный CMYK K100; 200, затем 1000 файлов, по три повтора.

- 1000 файлов запускаются только после PASS и медианы <120 с на 200. Пользователь 27.10.2026 прямо запросил оба масштаба; suite может последовательно выполнить 200 и затем 1000 для допущенных методов без повторного вопроса. В обычном GUI сохраняется отдельная кнопка.
- Не удалять результаты и не перезаписывать существующие запуски.
- Установки — только проектные, без глобальных PATH/registry/системных пакетов; сохранять версии, официальные URL и хеши. Отсутствующие или неработающие движки не скрывать.
- Публичная копия явно разрешена для нового репозитория `sunpole/uCode-Bench`. Существующий `sunpole/uCode` относится к старому EAN-13 проекту; его не менять. Локальные результаты и полные архивы сохранять; публичные отчёты очищать от машинных путей/учётных данных, зависимости и tools не коммитить.
