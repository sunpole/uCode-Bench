# Кнопочные настройки — 28.10.2026

Основа `17160fb`, ветка `codex/button-settings`, рабочая копия `016_uCode_PDF_test`. По присланному пользователем снимку заменены инженерные поля режимов на кнопки с русскими меню. Внутренние ключи/форматы настроек и возможности генерации сохранены. Набор12 задач, без новых зависимостей.

## Как пользоваться

Закройте старое окно и запустите **Start-uCode.cmd из этой тестовой копии**. Заголовок обновлённого окна: **uCode — QR / PDF · кнопочные настройки**. Старый запущенный процесс сам интерфейс не перечитывает; принудительно закрывать процессы/работу пользователя патч не пытается.

- Ядра выбираются подсвечиваемыми кнопками. **Считать** переключает физические ядра/логические потоки; **Выбор** открывает полный числовой список, включая нестандартные7/10/… . Недоступные сохранённые значения видны и могут быть сняты через меню; новые неподдерживаемые маски не объявляются рабочими.
- **Все параметры…**: **PDF → Обычный / Компактный**, **Контроль → Обычный / Минимум расходов**, **Выполнение → Последовательно / Процессы / Потоки**. В меню нескольких вариантов можно отметить несколько галочек. Подпись кнопки показывает текущий вариант либо число выбранных.
- **Память** выбирает auto/доли/безопасный максимум русскими пунктами. Собственный лимит вводится числом в **ГиБ**, затем **Добавить**; значения вроде1,5 поддержаны. Резерв ОС/проверки бюджета остаются прежними; память искусственно не заполняется.
- **Прогрев → Выключен / 1 / 2 / 3 пробных запуска**. **Параллельно → Автоматически** либо число исполнителей; техническое `0=CPU` вводить не требуется. Партия задаётся числом со стрелками.
- **Количество кодов** и **Повторов каждого режима** — числовые поля. В расширенной матрице **Добавить объём** добавляет введённое количество, **Объёмы** позволяет отметить нужные значения. Запятые/названия библиотечных режимов вручную не набираются. В основном управлении используется одно видимое количество; расширенный набор остаётся отдельным.
- **PDF и цвет**, **CPU / RAM**, политика повторов TXT и фильтр истории также используют кнопки/меню. Геометрия, CMYK и другие пользовательские числа имеют стрелки изменения. Поиск и отображение пути файла остаются текстом, выбор папки/файла — кнопкой.

Простой сценарий количества×ядер×повторов, точные2/30 запусков и все отдельные результаты остаются как в [CUSTOM_TESTS.md](CUSTOM_TESTS.md). Пресеты тестов не добавлены. Из расширенной панели убраны дополнительные кнопки фиксированных сценариев: основная кнопка запускает выбранные настройки. Старый scientific/API-профиль/gates сохранён.

## Реализация (12 задач)

1. Общий `ui_choices.ChoiceMenu` для одиночного и множественного выбора.
2. Русские подписи PDF/контроля/исполнения вместо редактируемых enum-строк.
3. Память кнопками, свои числовые ГиБ через NumberSet.
4. Ядра как подсвечиваемые кнопки и полный числовой выбор по ОС, без предела12/32/256 в меню.
5. Прогрев/автопараллелизм/партия без технического текстового ввода.
6. Объёмы через числовой ввод+Добавить+меню, совместимое хранение набора.
7. Кнопочный выбор и числовые стрелки печати/цвета/QA.
8. Кнопки CPU-производства и повторов TXT.
9. Фильтр истории кнопкой, поиск остаётся строкой поиска.
10. Выделенное состояние, блокировка при работе, сохранённые старые параметры.
11. Малые проверки меню/применения/совместимости/DPI и отличие заголовка нового окна.
12. README/WORK_LOG/контракты/карта/отдельный PR/исходный архив.
