# Графические отчёты — 29.10.2026

Патч `codex/graphical-test-reports` от `877b429` (PR18). Это следующая часть долга разделов10–11 ТЗ/P09: графическое сравнение сохранённых измерений. Живая кривая скорости и UI-режимы P09 не объявляются завершёнными.

## Как открыть

- Новый тест: обычная кнопка **Посмотреть отчёт / Отчёт в браузере**. Графики встроены в HTML CPU/RAM, конвейера, подбораПК, научного этапа, очереди консоли и нового текстового архива.
- Старый тест: **Тесты → Архив → выбрать запись → Графики ▾ → Выбранный тест**.
- Неимпортированный старый результат: **Тесты → Архив → Графики ▾ → Из JSON-файла…**, выбрать `pipeline.json`, `pc-search.json`, `lab.json`, `commands.json`, `scientific.json` или научный `report.json`.
- Старые HTML и JSON не перезаписываются: новый самодостаточный HTML создаётся в `output/test-archive/views/` (либо выбранной папке архива). PDF не читается, генерация/QA не повторяется.

CLI без запуска тестов:

```powershell
.\.venv\Scripts\python.exe -m ucode graphs --input "папка\pipeline.json" --output output\graphical-reports
```

## Архитектура и границы

`ucode/graphical_report.py`: нормализация и новый read-only HTML-снимок. `graphical_template.py`: встроенные SVG/JavaScript/CSS, без CDN/сети/новых зависимостей; Python-модуль входит в frozen runtime. Непроверенные строки явноUNVERIFIED, частичныеLIMITED. Ошибочные/неполные наборы не получают столбец, но остаются в таблице. Измеренные trial.seconds заново не меняются. Прогрев исключён.

Основная метрика новых тестов — `launcher_wall`, включая подготовку/процессы/выбраннуюQA/завершение. Скорость — count/median(time), её крайние значения — count/max(time) и count/min(time). Научное время метода безQA отдельно от оболочки; объединение отдельно от прямой генерации. Старый сводный `comparison.json`200→1000 без сырых повторов не подменяется искусственными повторами: выбрать вложенный научный `report.json`.

RAM: современные тесты — одновременный наблюдаемый RSS дерева, shared pages могут дублироваться; научный — исходная область `ram_scope` отдельного процесса/внешнего движка, смотреть исходный отчёт. Это не гарантированный пик физической памяти. CPU — процессыuCode, среднее взвешено по sampled_seconds наблюдений, min/max — сохранённые интервальные значения; число повторов с наблюдениями показывается в подсказке. ЗамерыCPU ВЫКЛ не означают0%.

Этапы показаны средними по повторениям: средние складываются в среднее полного времени. Медианы фаз не складываются в медиану целого. В конвейере одна фаза QR+PDF, суммы service_sum не складываются. Если состав фаз неизвестен/несовместим с полным временем, график этапов отсутствует. Подготовка/запуск/прочее — остаток, не диагноз диска/CPU.

ГенерацияSVG выполняется браузером при открытии; приRUNNING в рабочие HTML графический блок не добавляется. Финальный HTML строится после замеров отдельных повторов. Общее время серии и послетестовая подготовка отчёта могут включать расходы существующих writers; нулевые накладные расходы не обещаются. Производственная генерацияQR/PDF, её настройки/QA/мониторинг не меняются. Старые сохранённые времена остаются прежними. Количественного A/B расходов этого патча не проводилось.

Лимиты: JSON64МиБ,4096 вариантов, глубина вложенности8, график24 строки/страница; превышение количества явно указано. Все исходные параметры остаются вJSON/таблицах. Текст черезtextContent/HTML escaping; JSON внутриscript экранирует угловые скобки, U+2028/U+2029. Сеть/внешние зависимости/облако не используются. Архивные HTML не содержатPDF и кодовTXT. Работа безJavaScript — прежние таблицы/JSON.

Остались: живой совмещённый график время/скорость/накопленные коды/цель с ограниченным рядом, режимыUI A/B и измерение их расходов; обоснованное сравнение разныхПК/сборок; визуальная приёмка пользователем. P03 альтернативныеQR encoder, Disk/Hybrid и прочие долги карты этим патчем не закрываются.
