# P01 — интерфейс движков и наблюдаемая скорость

Это первый патч (10 задач) единого задания, а не завершение всей модернизации. Основа e51e2eb, ветка codex/modernization-p01. Общая очередь: [MODERNIZATION_PATCHES.md](MODERNIZATION_PATCHES.md).

## Реализация

- Новый `engines.py`: реестр генерации, отдельно от `generators.py` (стандарты кодов/валидация/QA) и `mergers/` (объединение). Реально доступен текущий **ReportLab QR + PDF**, версия определяется из установленного пакета; локально 4.4.9. Установка не выполняется.
- `EngineInfo` объявляет symbologies/colorspaces/output/PDF/execution/vector/streaming. Недоступный, неизвестный или несовместимый вариант отклоняется до создания каталога. Текущий режим serial; streaming и Grayscale не обещаются.
- `run_batch(generator="qr", engine="reportlab")` получает настройки, валидатор и независимый QA из модуля типа кода; encode/write — из выбранного движка. Чтобы подключить зарегистрированный модуль, сам pipeline редактировать не требуется. API без новых аргументов работает по-прежнему.
- Сверяются количество и порядок payload относительно TXT. Другой порядок от encoder — ERROR до записи PDF. Неправильный PDF от writer — INVALID по прежнему независимому decoder/QA; 100% не выдаётся.
- Префиксы/названия файлов для 12 цифр сохранены. Для иных будущих payload используется безопасный хеш-компонент имени, без встраивания произвольного содержимого в путь.
- Исторические worker encode/direct/singles используют тот же реестр. Import/prepare остаётся до таймера метода; prepare не выполняет прогрев или создание кода. Научный профиль пока фиксирован на QR V1-M и прежних параметрах; универсальная лаборатория — P08.
- Manifest и ОТЧЁТ включают точное имя/версию/capabilities движка. Каноническое время `code_encoding`; прежнее `qr_encoding` сохранено как alias модуля QR. Геометрия/CMYK/QA не ослаблены.
- Счётчик скорости хранит ограниченную очередь наблюдений: текущая скорость примерно за 3 секунды, средняя этапа отдельно. При редких callback реальный интервал может быть длиннее и записан в `speed_window_seconds`; промежуточные значения не выдумываются. Первое наблюдение без известного интервала имеет скорость 0. Повтор с новым base сбрасывает окно. Финальная скорость — count / elapsed операции.
- В UI показан фактический ReportLab и две скорости. В справке объяснены ограничения стороннего merger: без callback промежуточного процента нет, отмена ждёт возврата вызова. Принудительное завершение сторонних процессов этим патчем не добавлялось.
- CI больше не запускает 200/1000/10000 автоматически. Новый smoke создаёт 2/7 значений: both K100, multipage K100, singles CMYK C100. Большие скрипты сохранены для явных пользовательских запусков; старые артефакты не изменяются.
