# 0.3.2 — последовательный заказ

Один патч, ветка `codex/v032-order-flow`, поверх локальной 0.3.1. Запуск `Start-uCode.cmd`; прежние browser/legacy launcher сохранены. Новых зависимостей нет.

## Пользовательский сценарий

Явный выбор работающего QR открывает «Базу». Успешная загрузка/создание базы открывает «Путь», включая повторную загрузку того же файла. Повторное посещение вкладок не переключает их автоматически. Ошибки загрузки не меняют базу и текущую вкладку.

Во вкладке «Путь» есть редактируемое имя, «Автоимя», выбор папки и «Подтвердить». Формат: `QR_0000_12000_2026-10-30_18-42-07.pdf`: QR, последние 4 цифры первого значения, итоговый тираж, местная дата и время создания заказа. День месяца, без дня недели. Время не тикает; новая база создаёт новую метку. Ручное имя сохраняется при изменении параметров и между запусками. Расширение нормализуется; запрещены разделители путей, управляющие символы и зарезервированные Windows-имена.

«Подтвердить» проверяет запись, содержимое TXT, реальные образцы PDF и место с запасом; успех открывает «Оформление». Если путь ранее подтверждён, изменение тиража/оформления пересчитывает консервативный бюджет без повторного выбора папки. Проверка перед стартом повторно проверяет SHA256 TXT, подпись заказа, свободное место и возможность записи. Во время записи сохранены прежние guards. До подтверждения, при ошибках настроек/имени или нехватке места кнопка генерации недоступна.

Оформление: все прежние контролы слева, справа первый реальный QR базы без навигации. Без базы — подписанный образец с текущими настройками. Цвет экрана приблизительный, печатный CMYK проверяется отдельно. Во вкладки «Настройка» и «Просмотр» пользователь переходит сам; посещать настройки для запуска не обязательно. «Создать PDF» только в «Просмотре».

## Файлы и совместимость

В выбранной папке каждый успешный запуск получает отдельную папку с базовым именем заказа; при совпадении — `_2`, `_3` и т.д., без перезаписи. Один PDF имеет имя этой папки с `.pdf`; отдельные PDF — `0001.pdf`, `0002.pdf`… в папке заказа; при обоих вариантах они находятся в подпапке `singles`. Рядом сохраняются исходные данные заказа и отчёты, как прежде.

Исторические генераторы/QA сначала создают и проверяют результаты в прежнем формате. Затем worker публикует успешный заказ под выбранным именем. Статусы ERROR/INVALID/CANCELLED сохраняют диагностический исходный каталог. `output_layout` в manifest позволяет повторному аудиту читать новые имена в обычном и потоковом PDF. CLI и лаборатории без output_name сохраняют прежнее поведение. Научный профиль не менялся.

## Проверка

Целевые Python: order_flow, operator_web, operator_desktop, operation_host, operator_models, batch, streaming_pages. Для модульного запуска tests/test_streaming_pages нужен `PYTHONPATH=tests` из-за его прежнего импорта fixture. Node syntax и 2 operator_controls-теста.

Новый тест создаёт реальные PDF на 3 кода в multipage/singles/both, в памяти и принудительном streaming (6 запусков), проверяет коллизии и независимый повторный аудит всех результатов. Режим vector: итог LIMITED, без заявления о растровой проверке.

Реальное окно WebView2, одна короткая команда:

`.venv\Scripts\python.exe scripts\desktop_smoke.py --order-flow`

Результат в новой папке `output/desktop-smoke/<id>/result.json`. Проверяет тип→база→путь→оформление, нормализацию ручного имени, настоящий предпросмотр, PDF на 3 страницы, геометрию, 8 вкладок, повторный запуск и закрытие сервера. Это программный smoke, а не визуальная приёмка.

## Проверить пользователю

1. Обычное/минимальное окно и Windows 100/125/150%: без наложений и общей горизонтальной прокрутки, настройки доступны во внутренней области.
2. Открыть свой TXT: переход в «Путь», верное первое значение и количество. Повторно зайти в «Базу» без действий: остаться там.
3. Изменить имя и подтвердить папку: переход в «Оформление». Неверное имя/недоступная папка: понятная ошибка без перехода.
4. Изменить поле, размер, CMYK/подложку: первый код справа отражает изменения, пагинатора нет; место пересчитано.
5. Перейти в «Просмотр» и создать малый PDF; повторить с тем же именем: прежний результат сохранён, появился суффикс.

Не проверены визуально DPI, перенос между мониторами, большие тиражи и чистая установка. iQR и новые уровни коррекции не реализованы этим патчем.
