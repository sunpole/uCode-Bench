# Понятный выбор ядер — 28.10.2026

1. Перезапустите Start-uCode.cmd тестовой копии.
2. Откройте **Тесты → Ядра процессора**. Либо **CPU / RAM → Выбрать ядра для теста →**.
3. Отметьте числа, например **2** и **12**. Это два отдельных режима. **Все** означает все доступные физические ядра. **Все −2** исключает два физических ядра из теста, без эксклюзивной резервации для ОС.
4. Укажите количество кодов и повторы, нажмите запуск. Проверка PDF соответствует общим кнопкам проверки.
