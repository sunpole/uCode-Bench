# uCode 0.3.4 — стабильный выпуск

Релиз 0.3.4: локальный генератор QR и векторных PDF, современный интерфейс uCode, проверенные автономные пакеты.

## Основное

- Самостоятельное Windows-приложение: запуск `uCode.exe` из распакованной папки, без отдельной установки Python. Пользователь проверил открытие графического окна и `--smoke` на Windows.
- Локальные QR с содержимым: текст, ссылки, контакт, телефон, SMS, Wi-Fi, календарные события и другие статические профили. Автоматический выбор QR Model 2 V1–V40 с L/M/Q/H для **отдельного содержимого**.
- Числовой массовый QR, исходные научные тесты, настройки PDF, измерения производительности и ранее сохранённые результаты остаются совместимыми. Массовый числовой QR по-прежнему рассчитан на 12 цифр.
- Пакеты GitHub Actions: Windows x64, Linux x64 и macOS ARM64. В каждом архиве есть приложение со своей папкой; рядом опубликован `SHA256SUMS.txt`.

## Как запустить

- Windows: распаковать ZIP целиком, затем открыть `uCode\uCode.exe`. Требуется Microsoft WebView2 Runtime для графического окна.
- Linux: распаковать TAR.GZ и запустить исполняемый файл из `uCode/`; могут потребоваться Qt/GTK/WebKit и библиотеки графической среды.
- macOS: распаковать ZIP с `uCode.app`; пакет ARM64 (Apple Silicon), **без Apple Developer ID подписи/нотариализации**, поэтому Gatekeeper может ограничить запуск. Поддержка Intel Mac и чистая установка ещё не проверены.

Сохраняйте исходные TXT, существующие `output/`, `.local-state/` и пользовательские настройки: не распаковывайте новый архив поверх старой рабочей папки. Автоматическое обновление и подписанные инсталляторы ещё **не реализованы**.

## Отложено

Поддержка массовых числовых QR с переменной длиной обсуждалась, но **отклонена к разработке из-за отсутствия необходимости**. Ни в 0.3.4, ни в автоматически запланированные будущие версии эта функция не входит.

Более подробные ограничения и методика: `docs/PORTABLE_BUILDS.md`, `docs/STATIC_QR_V034.md`, `docs/MODERNIZATION_PATCHES.md`.
