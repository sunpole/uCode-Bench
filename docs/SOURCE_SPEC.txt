Согласен. Разделим uBarcodeBench на независимые модули и начнём с одного типа — квадратного QR Code. Не будем сразу разрабатывать всю систему для четырёх типов кодов.

Первый эксперимент — 200 QR-кодов, порог 120 секунд. Только методы, которые успешно пройдут проверку качества и окажутся быстрее этого порога, допустим к испытанию на 1 000 файлов.

## 1. Схема первого эксперимента

TXT — 200 последовательных номеров

200000000000 … 200000000199

Способ А

Генерация сразу одного PDF на 200 страниц

Способ Б

200 отдельных PDF → объединение разными движками

Контроль результата

200 страниц, верные номера, вектор, K100, точные размеры, читаемые коды.

Время меньше 120 секунд?

ДА

Допуск к 1 000

НЕТ

Пока исключить

Важное условие: сравниваем генерацию с генерацией, а объединение с объединением. Время создания 200 исходных файлов записываем отдельно, иначе сравнение будет нечестным.

## 2. Модульная структура

| Модуль            | Функция                                       |
| ----------------- | --------------------------------------------- |
| `M01_Data`        | Генерация 200 номеров и TXT                   |
| `M02_QR`          | Кодирование QR Code                           |
| `M03_PDF`         | Векторный PDF, CMYK K100                      |
| `M04_SingleFiles` | Создание 200 одностраничных PDF               |
| `M05_DirectPDF`   | Создание одного PDF на 200 страниц            |
| `M06_Mergers`     | Подключаемые qpdf, MuPDF, PyMuPDF, pikepdf    |
| `M07_Benchmark`   | Точные замеры времени, CPU, RAM               |
| `M08_Quality`     | Проверка номеров, страниц, цвета и считывания |
| `M09_Report`      | Таблица результатов и рейтинг скорости        |

Каждый способ объединения внутри `M06` будет отдельным заменяемым модулем, с собственными зависимостями, тестами и отчётом об ошибках.

Потом добавим Code 128, Data Matrix и EAN-13 как дополнительные модули кодирования. Основное приложение и система измерений останутся прежними.

## 3. Настройки теста

Для воспроизводимого эксперимента предлагаю зафиксировать:

| Параметр            | Значение                      |

| Размер модуля       | 0,5 мм                        |
| Свободное поле      | 4 модуля со всех сторон       |

| Графика             | Только вектор                 |
