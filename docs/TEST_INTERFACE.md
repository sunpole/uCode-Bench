# Тесты CPU / PDF — 28.10.2026

## Выбор и значения

- Панель показывает физические ядра/логические потоки текущего ПК и доступные программе количества в том же порядке. ОС опрашивается при запуске и открытии панели. Числа не зашиты под один компьютер.
- **Физические: 1 поток/ядро** берёт один логический представитель каждого ядра; **Логические CPU** считает потоки с SMT. «Оба варианта» создаёт два отдельных набора испытаний.
- Галочки **1 / 2 / 4 / 6 / 8 / 12 / Все −2 / Все** — варианты серии, не их сумма. По доступности добавляются 16/32 и фактический максимум. Недоступные количества отключены. **Свой CPU-набор** принимает другие числа через запятую. Старые сохранённые значения не теряются; недоступные будут пропущены с причиной.
- **Все −2 (N)** показывает реальное количество. При 14 ядрах/28 потоках это 12 физических или 26 логических. Два выбранных представителя исключены из теста, но не резервируются исключительно для Windows. При двух доступных единицах эта кнопка отключена, поскольку осталось бы ноль.
- В новой копии по умолчанию выбрано 1 физическое ядро, если известна топология; прогрев выключен. Сохранённые настройки не сбрасываются. При неизвестной топологии программа не выдумывает ядра/привязку.
- **Прогрев (раз)** — дополнительные пробные создания настоящих PDF перед замерами каждого варианта. Они проходят QA и сохраняются, но **не входят в медиану**. **0 = выключен**. Прогрев может подготовить файловый кэш; каждый запуск всё равно идёт в новом процессе, Python-пул между ними не сохраняется.
- **Замеры (раз)** — учитываемые запуски, обычно 3. Один вариант × (1 прогрев +3 замера) =4 прогона. Общий объём виден до старта. **Первый вариант** запускает одну комбинацию; **Вся выбранная серия** — все комбинации по очереди.
- **Объём ▾** даёт 200/500/1000/10000. **Сравнить PDF (первые)** оставляет четыре PDF/activity варианта на первых выбранных CPU/RAM/объёме. Полная QA лаборатории и историческая научная методика сохранены. Прежний выбор объединителей расположен во вкладке **Объединение**.

После лаборатории нажмите **Отчёт в браузере**. Windows helper запрашивает браузер HTTPS/HTTP и передаёт ему URI файла отдельным argv. Ассоциация `.html` с Блокнотом не используется и не меняется. Если браузер нельзя определить/запустить, причина выводится в строке состояния, без fallback в HTML-редактор. TXT/PDF/папки сохраняют обычные приложения. На других ОС используется Python webbrowser. Физическое открытие окна проверяет пользователь.
