# UI/UX и интерактивная справка uBrand

Основа PR21: `dbe8e76df003bad1a3e89016b93136a1bf905ada`; ветка `codex/ui-help-ubrand`. Пакет из 14 небольших задач. Генерация, конвейер и методика измерений не меняются.

## Найденные проблемы и изменения

| Проблема по коду и предоставленным экранам | Решение |
|---|---|
| Длинный текст справки без навигации и с устаревшими пояснениями | 12 тем и три коротких подраздела, предыдущая/следующая тема |
| Неясна разница основной генерации и тестового конвейера | Явное объяснение CPU; победитель теста не объявляется настройкой основной генерации |
| Нет фирменного знака | Предоставленный SVG uBrand, PNG для Tk, кнопка в шапке и значок окна |
| Главная кнопка могла запускать генерацию из справки | Запуск в справке отключён |
| Параметры порции, RAM, прогрева и процессов непонятны | Пояснения при наведении/фокусе, контекстный F1 и переходы к настройкам |
| Справочник команд был сплошным Markdown | Оформленный HTML с копированием примеров и таблицами текущего парсера |
| Нет графических объяснений | Схемы этапов; интерактивные CPU/порции и формула размера QR |
| Общий ERROR и остаточный «Запуск процессов…» после отказа RAM | Итог с числом готовых повторов, причиной и действиями; исходный статус сохранён |
| Технический JSON перегружает отчёт | Сводка перед таблицей; JSON в раскрываемом блоке |

Это структурная проверка и программные тесты, а не ручной визуальный аудит. Действующий AGENTS.md оставляет визуальную приёмку пользователю; скриншоты для приёмки не изготовлялись.

## Как пользоваться

Перезапустить `Start-uCode.cmd` тестовой копии после завершения активных задач. **Справка · F1** или клавиша F1 открывает тему текущей вкладки. Логотип открывает «О программе». Переход к настройкам не меняет значения и не запускает работу.

**Полная справка в браузере** создаёт новый `output/help/guide-…/help.html` и открывает браузер по умолчанию с якорем текущей темы. Оглавление, поиск, ссылки, копирование и схемы работают без сервера. Внешние контакты открываются по клику. HTML содержит локальный снимок CPU: при передаче файла этот снимок будет виден получателю.

Схемы учебные, не прогноз скорости и не готовые QR для печати. 10 000 кодов / порция 50 = 200 порций. Множитель 2 на 14 выбранных CPU = 28 процессов на том же наборе CPU. QR V1: `(21 + 2 × поле) × модуль`; модуль 1 мм и поле 6 дают 33 мм. Настройки схем не применяются к программе.

## Архитектура

- `help_content.py` — общий источник тем и маршрутов. Экспорт HELP_TEXT сохранён.
- `help_ui.py` — компактная навигация и схемы в текущем окне без полос прокрутки.
- `help_report.py` + `assets/help.html` — offline HTML; параметры получаются из текущего парсера. Не требуется соседний docs/ при установке пакета.
- `ui_hints.py` — подсказки со своими отменяемыми таймерами; закрываются при уходе мыши, потере фокуса, нажатии и уничтожении виджета.
- `brand.py` и assets/ubrand.svg/png — пользовательский знак. SHA256 SVG: `0050d768e2c21ec8311c97b45e5fcc3efc80da6fd2ec3d11e01fd10e6eba11d1`. SVG сохранён побайтно, PNG 128×128 отрисован уже установленным bundled Sharp. Новых зависимостей нет. Сгенерированные варианты не входят в продукт.
- `result_presentation.py` — только представление. QA, времена, исходные статусы и JSON не меняются. Настоящие ошибки и INVALID не маскируются предупреждением RAM.

## Ограничения и следующий шаг
