Сохраняются существующие Python-движки, CLI, научная методика, лаборатория, консоль, архивы, отчёты, проверка PDF и все 69 полей карты переноса. Точка запуска Start-uCode.cmd остаётся прежней. Изменения выполняются только в тестовой рабочей копии; старый релиз, пользовательские файлы и main до PR не меняются.

## Ограничения и правила доказательств

Крупные нагрузочные серии запускает пользователь. Визуальная приёмка — у пользователя; автоматический Tk/QA smoke не выдаётся за проверку мышью. GPU и остальные типы штрихкодов остаются явно недоступными, пока нет работающего модуля. Серверная статистика не подключается к неуказанному VPS: локальный подробный архив/экспорт сохраняются, отправка требует реального адреса и отдельного подключения.

Полный русский/English входит в общий план интерфейса; в этом переносе рабочая локализация остаётся русской, English не объявляется готовым. Пользовательские коды, команды консоли и исторические отчёты не переводятся. Завершение через диспетчер задач/сбой питания перехватить невозможно; обычные запросы закрытия проходят через подтверждение.

## Текущее состояние

После уточнения пользователя «точно как утверждено» основной renderer заменён с приближения Tk на исходный HTML/CSS. Пункты 1–12 подключены к OperatorService и прежним Python-функциям; Tk-каркас и gui-legacy сохраняются как исходники/возврат. Проверены модели и малые настоящие PDF, фон/инверсия/прозрачность, loopback API, независимость тестовых настроек, сохранение всех 69 исходных полей, смена заказа после проверки папки, серверное трёхсекундное подтверждение и принудительная остановка собственного дочернего процесса. Существующие лабораторные/консольные контракты используются напрямую. Новая команда консоли сохраняет также фон через --background/--paper.

Функциональный браузерный проход: настоящая база из 3 строк, QR, 1 физическое ядро, запись/место, 3-страничный PDF, UNVERIFIED, ресурсная статистика. Ошибок JS нет. Выход подвала за 1280×720 исправлен адаптацией центральной высоты; измерены root 704 px / footer bottom 701 px. Это не формальная визуальная приёмка.
