# 0.3.5: U01 — проверка обновлений через GitHub (этап разработки)

**Статус:** в отдельной ветке `codex/v035-update-check`; в stable `v0.3.4` этой функции нет. Не обновлять `main` до тестирования и выпуска.

## Назначение

После успешной публикации стабильной 0.3.4 следующий долг — обновления через GitHub. Начинаем с наименее рискованной части: **явной, только читающей проверки** последнего стабильного релиза.

### Вызов

Из исходников: `python -m ucode updates`.

Из следующей переносимой Windows-сборки: `uCode.exe --check-updates`. Аналогично из CLI Linux/macOS.

Команда выполняет один HTTPS-запрос к официальному GitHub Releases API `https://api.github.com/repos/sunpole/uCode-Bench/releases/latest`; принимает только `draft=false` и `prerelease=false`, строгие версии `vMAJOR.MINOR.PATCH`, официальный URL конкретного репозитория и имена пакетов для поддерживаемой ОС.

Показывает `installed`, `latest`, `CURRENT/UPDATE_AVAILABLE/LOCAL_NEWER`, ссылку релиза и наличие архива для ОС. Ошибки связи выводятся явно, без ложных сведений о наличии обновления.

**Никаких** фоновых запросов, автоматических скачиваний, установки, удаления/подмены файлов, изменения настроек или перезапуска. Обновления через релиз и пользовательский переход по ссылке возможны только вручную. Исходные `.local-state/`, `output/`, `tools/` и результаты не затрагиваются.

## Проверки и ограничения

- Все юнит-тесты применяют локальные JSON fixtures и mock HTTPS; в CI не нужен интернет к GitHub API.
- HTTP timeout 8 секунд, максимум ответа 256 КиБ.
- URL download проверяется строго, никакой сторонний домен не принимается.
- Архивы **не скачиваются** и не устанавливаются. До этапа U02 не проверяются цифровые подписи, `SHA256SUMS` в удалённых файлах или безопасное обновление.
- Версия пакета разработки пока остаётся 0.3.4 в исходниках: только создание ветки с U01 не является опубликованным повышением версии. Перед отдельным выпуском новой версии нужен PEP440 bump и полноценная QA.

## Следующий этап U02/U03 — только после приёмки U01

- Выделенный интерфейс обновления без автоматических действий, явное согласие на загрузку, подробная информация о версии.
- Загрузка на временный диск со строгой проверкой SHA-256 из подписанного или доверенного релизного manifest, запрет неизвестных хостов/путей, ограничения размера, отсутствие произвольного исполнения скачанного файла.
- Установка только в отдельную версионную папку после закрытия программы, откат и атомарное переключение запуска, сохранение пользовательских данных. Для Windows — WebView2, для macOS — подписывание и Gatekeeper, для Linux — нативные зависимости.
- Финальная проверка на чистых машинах и новая стабильная версия GitHub Release.

Бэклог QR с числовой переменной длиной по решению пользователя остаётся **отклонённым**, не входит в U01.
